# 🎵 Music Player

A responsive and interactive **Music Player** created using **HTML, CSS, and JavaScript in a single HTML file**.

The music player provides an easy-to-use interface for playing and controlling audio, with features such as play/pause, next/previous track navigation, progress control, volume adjustment, and a clean responsive design.

## ✨ Features

* ▶️ Play and pause music
* ⏭️ Next track navigation
* ⏮️ Previous track navigation
* 🎵 Track information display
* 📊 Music progress bar
* 🔊 Volume control
* ⏱️ Current time and duration display
* 🖱️ Interactive buttons and controls
* ✨ Smooth transitions and hover effects
* 📱 Responsive design for different screen sizes
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Music player structure and audio elements
* **CSS3** – Styling, layout, responsive design, hover effects, and transitions
* **JavaScript** – Audio controls, track navigation, progress handling, and volume control

## 📂 Project Structure

```text
musicplayer.html
```

All HTML, CSS, and JavaScript code is contained in a **single `musicplayer.html` file**.

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/AimanShabbir03/CodeAlpha_MusicPlayer.git
```

2. Open the project folder.
3. Open `musicplayer.html` in any modern web browser.
4. Use the music controls to play, pause, and navigate between tracks.
